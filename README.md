# Что готовим

Семейное меню на месяц: домашние супы и вторые блюда без повторов, план на неделю и список покупок, общий для всех телефонов.

- **Неделя** — что на завтрак, обед, ужин и перекус. Суп варится на 2–3 дня, второе на 1–2 дня. Любое блюдо можно заменить, выбрать вручную или закрепить.
- **Месяц** — одной кнопкой собирается меню на месяц. Повторы внутри месяца исключены, блюда прошлого месяца выпадают реже, два похожих ужина подряд не ставятся.
- **Покупки** — список на неделю. Обязательные покупки идут каждую неделю, продукты для блюд считаются на число людей и дней. Любой продукт можно заменить или убрать, если он уже есть дома. Можно добавить своё и отправить список в мессенджер.
- **Рецепты** — 63 домашних рецепта, порции пересчитываются, любимые чаще попадают в меню.
- **Семья** — код синхронизации без регистрации, число людей, приёмы пищи, «не едим», обязательные покупки.

Стек: Next.js 16 (статический экспорт), React 19 + React Compiler, Tailwind 4, Firebase Firestore (офлайн-кэш и живая синхронизация), PWA.

## Разработка

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статический сайт в out/
npm run lint
node scripts/icons.mjs   # пересобрать PNG-иконки из public/logo.svg
```

Без настроек Firebase приложение работает в локальном режиме: данные лежат только в браузере этого устройства.

## Синхронизация между телефонами (Firebase, бесплатно)

1. Зайди на [console.firebase.google.com](https://console.firebase.google.com) и создай проект. Google Analytics не нужна.
2. **Build → Firestore Database → Create database**. Регион — `eur3 (europe-west)`, режим — production.
3. Во вкладке **Rules** вставь содержимое [firestore.rules](firestore.rules) и нажми **Publish**.
4. **Project settings → General → Your apps → Web (</>)**. Зарегистрируй приложение и скопируй значения из `firebaseConfig`.
5. Создай файл `.env.local` по образцу [.env.example](.env.example) и вставь в него ключи.
6. Перезапусти `npm run dev`. В шапке появится статус «Синхронизировано», а на вкладке «Семья» — код семьи.

На втором телефоне открой ссылку из кнопки «Пригласить» или введи код вручную. После этого меню и отметки в списке покупок общие и обновляются за пару секунд. Без сети изменения копятся на телефоне и отправляются, когда связь появится.

Ключи веб-приложения Firebase не секретные. Доступ ограничивают правила: данные открываются только по коду семьи (12 случайных символов), а просмотреть список кодов нельзя.

Бесплатного тарифа Spark хватает с большим запасом: 50 000 чтений и 20 000 записей в день.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и запушь ветку `main`.
2. **Settings → Secrets and variables → Actions → Variables**. Добавь `FIREBASE_API_KEY`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_PROJECT_ID`, `FIREBASE_APP_ID`.
3. Workflow [pages.yml](.github/workflows/pages.yml) соберёт сайт и выложит его в ветку `gh-pages`.
4. **Settings → Pages → Source: Deploy from a branch → `gh-pages`**.

Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`. На телефоне его можно поставить как приложение: «Поделиться → На экран „Домой“» на iPhone или «Установить приложение» в Chrome.

## Устройство

```
app/
  _week/WeekView.tsx     неделя: полоска дней на телефоне, доска на компьютере
  month/                 календарь месяца и сборка меню
  shop/                  список покупок
  recipes/               каталог и страница рецепта (SSG для каждого)
  family/                код семьи и настройки
  elements/              Nav, Sheet, DishSheet, MealCard, Plate, RecipePicker…
  lib/
    recipes.ts           каталог рецептов (на 4 порции)
    ingredients.ts       справочник продуктов, отделы магазина, форматирование
    planner.ts           генерация месяца, замены, изменение дней
    shopping.ts          сборка списка покупок
    store.ts             код семьи, Firestore / localStorage, статус синхронизации
    hooks.ts             подписки на документы
```

Данные в Firestore лежат по путям `spaces/{код}` (настройки), `spaces/{код}/months/{YYYY-MM}` (готовки месяца) и `spaces/{код}/weeks/{понедельник}` (отметки, замены и своё в покупках).
